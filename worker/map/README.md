# Map worker

Turns a game map image (isometric diorama on a plain background) into a layered GLB scene for three.js. It is
separate from the single-object Hunyuan3D worker: the web app has its own page (`/app/maps`), table
(`map_generation`) and API (`/api/maps`) for it.

## Pipeline (`mapgen.py`)

| Stage | Model / method | Output |
|---|---|---|
| Depth | MoGe-3 ViT-g (`Ruicheng/moge-3-vitg`, MIT). The sparse refiner needs CUDA (`flex-gemm`), so it runs off on Mac | point map + camera |
| Ground | RANSAC plane, edges aligned by minimum-area rectangle | map frame (x, y up, z) |
| Objects | SAM 2.1 Hiera-L (`facebook/sam2.1-hiera-large`, Apache-2.0) auto masks on 480 px tiles + one full-image pass | masks |
| Classify | height above ground + color → tree / rock / cliff / water / decal; tall pixels no mask claimed → cliff | props, water mask |
| Terrain | ground-level samples → 512-cell heightmap + image-projected albedo, holes diffused | `Terrain` |
| Props | RGBA crop per object; similar trees/rocks share ≤ 3 variants; each variant generated by the Hunyuan3D-2.1 worker (50 steps, octree 256, PBR textured, 30k faces) | `Props/<variant>#n` (instanced) |
| Compose | flat water surface over carved bed, low-res heightfield collider | `Water`, `Collision` |

Scene units: metres, 100 m across the longer edge, centred on the origin, ground at y = 0. Node names are the
contract with the viewer (`web/src/components/map-scene.tsx`).

## Run

```bash
worker/map/setup.sh          # once: .venv + MoGe checkout (pinned) + flex-gemm on CUDA hosts
worker/map/run.sh            # port 8083; start.sh starts it when web/.env.local has MAP_WORKER_URL
```

`web/.env.local`: `MAP_WORKER_URL=http://localhost:8083` (token defaults to `HUNYUAN_WORKER_TOKEN`; set
`MAP_WORKER_TOKEN` to use another). The Hunyuan3D-2.1 worker (`:8081`) must be running: props are generated there, and it
fetches the crops from `PUBLIC_URL/v1/crops/...` (default `http://localhost:8083`, allowed by its
`ALLOWED_IMAGE_HOSTS=localhost`).

## Timing (M4, 32 GB)

Depth ~30 s and segmentation ~3 min on CPU (faster on MPS); each prop variant ~24 min in the Hunyuan3D-2.1 worker
(shape ~16 min at 50 steps, PBR texture ~8 min; estimated from the 30-step M4 measurements in
`docs/adr/0003-hunyuan3d-2.1-side-by-side.md`). A map with 12 variants takes about 5 hours on a Mac. Credits: 0 for now
(`MAP_COST` in `web/src/lib/config.ts`).

## Limits

- Made for isometric dioramas: one dominant ground plane, plain backdrop. Top-down or perspective scenes fit poorly.
- Heightmap terrain cannot hold overhangs; anything tall becomes a prop.
- Hidden sides (behind cliffs, the back of props) are guessed.
